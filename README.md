An end-to-end Data Analytics project demonstrating the complete analytics lifecycle from Data cleaning and Exploratory data analysis (EDA) to SQL querying and interactive Dashboard development using Power BI. The project transforms raw e-commerce sales data into actionable business insights.


# Project Overview

The objective of this project is to analyze an e-commerce sales dataset, perform data cleaning and exploratory data analysis (EDA), execute SQL-based business queries, and build an interactive Power BI dashboard to support business decision-making.

This project simulates a real-world analytics workflow followed by Data Analysts.


# Business Problem

Businesses generate large volumes of sales data every day. The challenge is to transform this raw data into meaningful insights that help stakeholders understand:

- Sales performance
- Profitability
- Customer segments
- Regional performance
- Sales trends over time

This project addresses these challenges through data analysis and interactive visualization.

# Power BI Dashboard

The dashboard includes:

- KPI Cards
  - Total Sales
  - Total Profit
  - Total Orders

- Sales by Category

- Profit by Region

- Sales Trend Analysis

- Interactive Slicers
  - Region
  - Segment
  - Order Year


# Key Business Insights
